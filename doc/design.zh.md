# PageTree

PageTree 用页面树组织 Obsidian 笔记，让每个页面既能写内容，也能包含子页面。

底层仍使用普通 Markdown 文件：每个页面对应一个 `.md` 文件；有子页面时，子页面存放在与父页面文件同级、同名的文件夹中。

页面层级由实际的文件与文件夹关系决定，不向笔记正文添加额外的结构标记。

停用或卸载插件后，笔记仍以普通 Markdown 文件保留，不影响继续阅读和编辑。

支持 Windows、macOS 和 iOS 上的 Obsidian，需 Obsidian 1.8.7 或更新版本。

启用插件后，在命令面板运行「打开 PageTree」，点击「+」创建页面；桌面端通过拖拽调整层级和顺序，移动端使用页面旁的「…」菜单。

删除页面时，其所有子页面也会一并删除，操作前会弹出确认提示。

## 为什么需要 PageTree

市面上很多文档软件用文件和文件夹组织内容，但文件夹本身不能承载正文，只能作为容器。

另一些软件提供页面树和丰富的编辑样式，但内容依赖专有结构，AI 难以直接读写，需要额外接入 API。离开原软件后，内容不易阅读；多设备同步出错时，也可能波及较多内容。

Obsidian 使用本地 Markdown 文件保存笔记。一些社区插件通过向笔记中添加结构标记来维护页面层级。

PageTree 对此作了改良：用文件与文件夹关系维护层级，不侵入正文。
